## Build

Run `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex`, or `pdflatex main.tex` twice.
The bibliography is embedded in main.tex for reliable submission compilation. BibTeX is not required.
references.bib and the unmodified official sn-apacite.bst are retained as bibliography sources.
If references change, update the embedded bibliography or regenerate it from references.bib.
Fig1.tex through Fig3.tex are editable diagram sources; the manuscript uses their vector PDFs.
Fig4.pdf is generated by build_evidence.py from existing result artifacts.

The built-in single-file compiler cannot resolve this project's external
sn-jnl.cls class. The existing local TeX installation compiles the full project;
main.pdf is the verified result.

## Evidence regeneration

From the project root, with NumPy, PyYAML, and Matplotlib available:

```bash
python3 Paper/IJCV/build_evidence.py
```

This reads results_v2_factorial and results_descriptor_controls without
modifying their artifacts or retraining models. It writes evidence_crossed.json
and Fig4.pdf, validates aligned development probes, and hashes the source
metric and outcome files in its manifest. The revised intervals are embedded
in main.tex; update them deliberately if the analysis inputs or settings change.
The script does not reproduce the historical model-training source snapshots
or the separate official-test analysis.
